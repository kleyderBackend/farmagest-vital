# FarmaGest Vital

Sistema web academico para gestion de inventario y ventas de una farmacia con catalogo ecommerce.

## Modulos

- Catalogo publico de productos.
- Carrito de compras.
- Generacion de pedidos.
- Panel administrativo.
- Control de productos, stock y vencimientos.
- Alertas de bajo inventario.
- Reporte basico de pedidos y ventas.
- Script SQL inicial para base de datos relacional.

## Tecnologias

- HTML
- CSS
- JavaScript
- LocalStorage para modo demostracion
- SQL para la estructura de base de datos

## Como abrir

Abre estos archivos en el navegador:

```text
index.html
admin.html
```

El sistema funciona como demo local sin instalar nada. Los datos se guardan en el navegador.

## Base de datos

La estructura SQL esta en:

```text
database/schema.sql
```

Ese archivo sirve como base para implementar luego MySQL o PostgreSQL con backend.
